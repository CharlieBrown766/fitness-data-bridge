# Support

Report reproducible defects and documentation issues through the repository's
[GitHub Issues](https://github.com/CharlieBrown766/fitness-connector/issues).

Do not include credentials, API tokens, Apple Health exports, Xunji databases,
training records, receipts, backups, logs, or other personal data in an issue.
